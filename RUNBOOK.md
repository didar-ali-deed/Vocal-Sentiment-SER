# Speech Emotion Recognition: setup and verification

Run commands from the repository root. The existing `scripts/venv` may point
to a Python installation from another computer, so create a fresh environment:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Download the RAVDESS and TESS datasets into `data/ravdess` and `data/tess`,
then run the pipeline:

```powershell
python scripts/preprocess.py `
  --tess_path data/tess `
  --ravdess_path data/ravdess `
  --output_dir "Preprocessed Data" `
  --workers 4

python scripts/wav2vec_feature_extraction.py `
  --input_path "Preprocessed Data/combined_data.csv" `
  --output_path "Extracted Features/combined_wav2vec_features.csv" `
  --batch_size 8

python scripts/train_emotion_classifier.py
python scripts/test_emotion_classifier.py
python scripts/app.py
```

The first prediction downloads/caches `facebook/wav2vec2-base`. The Flask app
expects `models/emotion_classifier/` to contain the classifier checkpoint,
label names, metadata, and `feature_scaler.pkl` generated by training.

Useful checks:

```powershell
Invoke-WebRequest http://127.0.0.1:5000/health
```

Feature extraction now performs true padded batch inference with attention-mask
aware pooling. The app loads models lazily, rejects audio longer than 30 seconds,
uses random temporary filenames, deletes uploads after inference, and writes
prediction history atomically.
